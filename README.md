# 整人專家｜醫美購物網站

大學課程期末專案，課程要求以「購物網站」為主軸、主題自訂，
與同學協作完成前後端開發，本專案負責前端頁面設計與切版。

## 專案主要內容
1. 負責前端頁面設計與切版，包含首頁 Banner 主視覺、商品總覽、
   關於我們、登入註冊、後台登入、搜尋列、會員與購物車圖示等版面配置。
2. 依照設計稿還原品牌風格，並將醫美服務相關宣傳圖文整合進頁面中。
3. 完成前端頁面切版後，與同學合作進行前後端整合，將靜態頁面
   串接後端資料與功能，協同完成整體購物網站的實作。

## 使用技術
- HTML5
- CSS3

## 專案結構
- `assets/`：圖片、CSS 樣式等靜態素材
- `pages/`：各功能頁面
